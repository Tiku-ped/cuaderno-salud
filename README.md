# Cuaderno de salud

App web para que las familias guarden los documentos de salud de sus hijos (recetas, exámenes, informes) y lleven recordatorios de vacunas y controles.

Todos los datos se guardan únicamente en el dispositivo del usuario (IndexedDB). No hay servidor, cuentas, analítica ni llamadas a terceros.

**Abrir la app:** https://tiku-ped.github.io/cuaderno-salud/

**Ver una demo con datos de ejemplo:** https://tiku-ped.github.io/cuaderno-salud/#demo

En el teléfono: abre el enlace en Safari o Chrome y usa "Agregar a pantalla de inicio" para tenerla como app. Desde Ajustes puedes descargar un respaldo de los datos y activar un PIN.
